## ✨ Overview

**Nimbus Weather** is a sleek and responsive weather application designed to deliver real-time weather information with a clean glassmorphism-inspired interface.

Built entirely using **Vanilla JavaScript, HTML, and CSS**, this project focuses on performance, user experience, and modern frontend design.

---

## 🚀 Features

✅ Real-time weather updates  
✅ Search weather by city  
✅ World weather dashboard  
✅ Dynamic weather icons  
✅ Beautiful glassmorphism UI  
✅ Responsive design  
✅ Smooth animations  
✅ Multi-page navigation
